# 🦖 공룡알 숫자나라

33개월 아이를 위한 숫자 학습 게임. 공룡알을 1번부터 순서대로 탭해서 깨면
리얼 공룡이 나와요. (부모와 함께 플레이하는 용도)

## 폰에 설치하기
1. 안드로이드 크롬에서 게임 주소 열기
2. 메뉴(⋮) → "홈 화면에 추가"
3. 홈 화면 아이콘으로 실행 (인터넷 없어도 동작)

## 목소리
기본으로 마이크로소프트 선히(SunHi) 음성 mp3가 내장되어 있어 모든 폰에서 같은 목소리가 나옵니다.
파일이 없으면 폰의 TTS로 자동 폴백합니다.

**다른 음성으로 전부 재생성**: `scripts/make-voice.py`의 `VOICE`를 바꾸고
`python scripts/make-voice.py` 실행 (예: `ko-KR-InJoonNeural` 남성 음성)

**아빠/엄마 목소리로 교체**: 같은 파일명으로 `assets/voice/`에 덮어쓰면 됩니다:
- `n01.mp3` ~ `n10.mp3` — "하나!" ~ "열!"
- `ask01.mp3` ~ `ask10.mp3` — "하나! 찾아보세요. 하나!" ~
- `dino01.mp3` ~ `dino10.mp3` — 공룡 이름 (`data/dinos.js` 순서)
- `praise01.mp3` — 클리어 칭찬
교체 후 `sw.js`의 `CACHE` 버전을 올려야 폰에 반영됩니다.

## 공룡 이미지 바꾸기 (선택)
`assets/dinos/`의 이미지를 교체하면 됩니다. 파일명·확장자 매핑은
`data/dinos.js`에서 수정 (이미지 출처: `assets/dinos/CREDITS.md`).

## 개발
- 로컬 실행: `npx http-server -p 8123 -c-1`
- 테스트: `npm test`
- 파일을 바꾸면 `sw.js`의 `CACHE` 버전을 올려야 폰에 반영됩니다.
