# 공룡알 숫자나라 — 설계 문서

날짜: 2026-06-10
대상 사용자: 33개월 남아 (부모와 함께 플레이)
플랫폼: 안드로이드 폰 (PWA 웹앱)

## 목적

공룡을 좋아하는 33개월 아이에게 **1~10 순서 세기**와 **숫자 모양 인식**을 놀이로 가르친다.
현재 아이 상태: 말로 세기는 하지만 순서가 뒤섞임 ("하나, 둘, 셋, 일곱, 여덟, 아홉열").

## 게임 규칙

1. 화면에 숫자가 적힌 공룡알들이 배치된다.
2. 아이가 **1번부터 순서대로** 알을 탭한다.
3. 정답 탭: 알이 흔들림 → 금 감 → 깨지며 리얼 공룡 등장. 음성으로 "둘! 티라노사우루스!" 재생.
4. 오답 탭: 알이 도리도리 흔들리기만 한다 (부정적 피드백 없음). 같은 레벨에서 2회 연속 오답 시 정답 알이 반짝여 힌트를 준다.
5. 모든 알을 깨면 클리어: 빵빠레 + "잘했어!" 음성 + 별 획득 → 다음 레벨 버튼.

## 학습 설계

- **숫자 읽기: 고유어** (하나, 둘, 셋 … 열). 화면에는 아라비아 숫자(1~10)를 크게 표시해 모양을 익힌다. 한자어(일, 이, 삼) 읽기는 추후 버전.
- **레벨 구성 (단계형)**:
  - 레벨 1: 알 3개 (1~3)
  - 레벨 2: 알 5개 (1~5)
  - 레벨 3: 알 10개 (1~10, 두 줄 배치)
- 알 위치는 매판 무작위로 섞는다 — 위치 암기가 아니라 숫자 인식이 목표.
- 진행도(레벨별 별)는 localStorage에 저장. 시작 화면에 별 표시.
- 33개월 발달 고려: 성공 경험 우선, 시간 제한 없음, 실패 패널티 없음, 큰 터치 영역(최소 15% 화면 폭).

## 화면 구성

1. **시작 화면**: 타이틀 + 큰 "시작!" 버튼 + 진행도 별. (첫 터치가 오디오 잠금 해제를 겸함)
2. **게임 화면**: 상단에 현재 목표 숫자 크게 표시, 알들 배치, 깬 알 자리에는 부화한 공룡이 남음.
3. **부화 연출**: 알 흔들림 → 금 → 펑(파편 + 반짝이) → 공룡 PNG 팝업 + 이름 음성.
4. **클리어 화면**: 부화한 공룡들 + 빵빠레 + 별 + "다음 레벨" 버튼.

가로/세로 모두 대응 (CSS 반응형).

## 그래픽

- **SVG (코드로 직접 그림)**: 배경(공룡 시대 풍경), 알, 숫자 표시, 금/파편/반짝이 연출, 버튼.
- **PNG (리얼 이미지)**: 부화하는 공룡 10종. 육식공룡 위주 (예: 티라노사우루스, 벨로시랩터, 스피노사우루스, 기가노토사우루스, 알로사우루스 등) + 초식 일부 섞기.
- 이미지 출처: 퍼블릭 도메인/CC0 복원도를 수집해 시작. 품질이 아쉬우면 부모가 AI 생성 이미지로 교체.
- **교체 가능 구조**: `assets/dinos/dino01.png` … `dino10.png` 파일명 규약. 파일만 바꾸면 교체 완료. 공룡 이름은 설정 파일(JS 객체)에서 파일명과 매핑.

## 소리

- **음성: 기기 TTS (Web Speech API, 한국어)** 를 기본으로 사용.
- **교체 가능 구조**: `assets/voice/` 폴더에 정해진 이름의 오디오 파일(예: `n01.mp3`~`n10.mp3`, `praise01.mp3` 등)이 존재하면 TTS 대신 그 파일을 재생. 나중에 부모 목소리 녹음으로 교체 가능.
- 효과음(알 깨짐, 빵빠레)은 무료 효과음 파일 사용.
- 모바일 브라우저 오디오 정책 대응: 시작 버튼 첫 터치에서 오디오 컨텍스트 잠금 해제.

## 기술 구조

- **순수 HTML/CSS/JS 단일 페이지 앱.** 빌드 도구·프레임워크 없음.
- 파일 구성:
  - `index.html` — 진입점
  - `css/style.css` — 스타일
  - `js/game.js` — 게임 상태/규칙 (레벨, 순서 판정, 진행도)
  - `js/audio.js` — 소리 레이어 (파일 있으면 파일, 없으면 TTS 폴백)
  - `js/render.js` — SVG/DOM 렌더링과 애니메이션
  - `data/dinos.js` — 공룡 이름·이미지 매핑
  - `assets/dinos/*.png`, `assets/voice/*`(선택), `assets/sfx/*`
  - `sw.js` + `manifest.json` — PWA (오프라인 캐시, 홈 화면 설치)
- **배포: GitHub Pages.** 폰 크롬에서 "홈 화면에 추가"로 설치.
- 진행도 저장: localStorage (키: `dino-num-progress`).

## 오류 처리

- TTS 미지원/실패: 소리 없이 시각 연출만으로 진행 가능해야 함 (부모가 옆에서 읽어줌).
- 이미지 로드 실패: 기본 SVG 공룡 실루엣으로 대체 표시.
- localStorage 접근 불가: 진행도 저장 없이 매번 레벨 1부터 (게임은 정상 동작).

## 검증

- 게임 규칙 로직(`game.js`)은 DOM과 분리해 작성하고 간단한 단위 테스트로 검증 (순서 판정, 레벨 진행, 힌트 트리거).
- PC 브라우저(크롬 모바일 에뮬레이션)에서 전체 플레이 테스트.
- GitHub Pages 배포 후 실제 안드로이드 폰에서 최종 확인: 설치, 오프라인 실행, TTS 음성, 터치 반응.
